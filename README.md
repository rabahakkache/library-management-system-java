
# Library Management System

A simple Library Management System developed in Java using Object-Oriented Programming (OOP).

## Features

- Add new books
- Display all books
- Search for books by ID
- Remove books
- Borrow and return books
- Validate user input
- Prevent duplicate book IDs

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
